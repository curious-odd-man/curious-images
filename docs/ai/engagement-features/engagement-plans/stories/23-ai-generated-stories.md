# AI-Generated Stories

## What it does
A short narrative paragraph summarizing a period (e.g. a summer, a trip) generated by a local LLM,
e.g. "Summer 2018 was centered around hiking in Norway with Anna..."

## Depends on shared infra
- §C (`OllamaTextService`) directly — this is the feature that defines that shared service's
  narrative-generation contract, reused verbatim by **Monthly Story** (feature 04) and available to
  **Ask Your Archive** (feature 18) for answer phrasing. Build this feature's prompt/service first
  if implementation order is otherwise unconstrained, since two other features depend on it.

## New data
None new — this is a rendering/synthesis layer over data already aggregated by
`MonthlyStoryService` (feature 04)/`AlbumGenerationJob` (events/locations/people).

## Backend design
- `domain/ai/NarrativeGenerationService.generate(StructuredPeriodSummary summary)`: builds a
  prompt strictly from **structured facts already computed elsewhere** — event names, location
  names, dominant people, photo count, date range — never raw pixel data. This is the same
  discipline called out in feature 04: the LLM narrates a summary object, it does not "see" the
  photos.
  - Example prompt shape: "Write a short, warm 2-3 sentence summary of a period described by:
    dates=[...], locations=[...], people=[...], events=[...], photo_count=N. Do not invent details
    not listed."
  - `StructuredPeriodSummary` is a small shared DTO — reuse it as the same input type
    `MonthlyStoryService` builds internally so the two features share one prompt-building code
    path rather than each inventing its own.
- Always show a plain-fact fallback ("142 photos from a trip to Norway, June–July 2018") if Ollama
  is unavailable/disabled — this feature must never be a hard dependency for viewing a period's
  content, only an enrichment.

## UI
- No dedicated screen — this renders as the narrative paragraph inside Monthly Story's detail view
  (feature 04) and/or a "Year in Review" variant of the same, for a full calendar year instead of a
  month.
